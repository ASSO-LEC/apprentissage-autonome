Compréhension de l'oral

Lisez les questions. Écoutez les documents puis répondez aux questions.

Total : 25 points

Exercice 1

4 points

Vous écoutez le message suivant sur votre répondeur téléphonique.

1. Vous allez faire quelle activité ? (1 pt)

2. Le premier cours se passe le… (1 pt)

3. Qu'est-ce que Monsieur Morel demande ? (1 pt)

4. Il faut venir avec… (1 pt)

Exercice 2

4 points

Vous êtes en France. Vous entendez cette annonce à l'aéroport.

1. Ce message demande aux passagers… (1 pt)

2. Le retard est de… (1 pt)

3. Quel temps fait-il ? (1 pt)

4. Qu'est-ce que vous pouvez acheter ? (1 pt)

Exercice 3

4 points

Vous travaillez en France. Votre collègue Romain laisse le message suivant sur votre répondeur téléphonique.

1. Pourquoi Romain est absent du bureau aujourd'hui ? (1 pt)

2. La réunion de lundi est à… (1 pt)

3. La réunion se passe dans… (1 pt)

4. Que va faire Romain ce soir ? (1 pt)
