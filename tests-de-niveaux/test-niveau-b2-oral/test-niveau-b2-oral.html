DELF B2 — Compréhension de l'oral

Vous allez écouter plusieurs documents. Pour répondre aux questions, cochez la bonne réponse.

Total : 25 points (Exercices 1, 2 et 3)

Exercice 1

9 points

Vous allez écouter 2 fois un document. Vous écoutez une émission à la radio. Lisez les questions, écoutez le document puis répondez.

1. D'après le journaliste, on trouve souvent sur les réseaux sociaux des articles sur... (1 pt)

2. Selon le document, il est... de modifier notre rythme de sommeil. (0,5 pt)

3. Quel rythme de vie adoptent les sportifs professionnels ? (2 pts)

4. D'après le journaliste, les personnes qui se couchent tard sont plus... le soir. (1,5 pt)

5. Il est socialement bien vu de se lever tôt car cela permettrait d'être plus... (0,5 pt)

6. Faire du sport le matin est considéré comme un luxe car... (2,5 pts)

7. La pratique du sport en fin de journée est avantageuse car elle permet... (1 pt)

Exercice 2

9 points

Vous allez écouter 2 fois un document. Vous écoutez une émission à la radio. Lisez les questions. Écoutez le document puis répondez.

1. L'entreprise américaine Google a lancé l'idée d'une nouvelle... (0,5 pt)

2. Dans l'entreprise Sanofi, la nouvelle organisation concerne... (1 pt)

3. Quel est l'objectif principal de cette organisation ? (1 pt)

4. Du fait de cette organisation, les employés... (1,5 pt)

5. Chez les employés, cette organisation peut... (1,5 pt)

6. Comment les employés les plus âgés réagissent-ils à ce système ? (1 pt)

7. La journaliste estime que les hôtels de travail... (2,5 pts)

Exercice 3

7 points

Vous allez écouter 1 fois 3 documents. Lisez les questions, écoutez les documents puis répondez.

DOCUMENT 1

1. Qu'est-ce qu'on constate dans l'évolution de la presse jeunesse actuellement ? (0,5 pt)

2. Selon Elsa Maudet, les nouveaux types de magazine vont... (1 pt)

DOCUMENT 2

3. Pour l'intervenant, les jeux de société permettent d'être... (1,5 pt)

4. D'après l'intervenant, chez les plus jeunes, les jeux de société favorisent principalement... (2 pts)

DOCUMENT 3

5. Selon l'intervenante, un robot émotionnel est capable... (1,5 pt)

6. Dans quel domaine les robots sont-ils bénéfiques pour les enfants ? (0,5 pt)
